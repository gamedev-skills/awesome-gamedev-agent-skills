# Web engine skills

Nine Agent Skills for browser games: Phaser 4.2 core and Arcade Physics, PixiJS
8.22 rendering, three.js r187 scene, glTF, material, and lighting workflows, and
RPGJS v5 core, events and maps, and testing.

Each subdirectory is one skill. Existing projects keep their locked dependency
versions; see [`VERSION-SUPPORT.md`](../../docs/VERSION-SUPPORT.md).

See [`docs/SKILL-FORMAT.md`](../../docs/SKILL-FORMAT.md) for the authoring standard.
