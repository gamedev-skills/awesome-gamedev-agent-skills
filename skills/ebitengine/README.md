# Ebitengine skills

One Agent Skill for creating, improving and packaging playable 2D games in Go
with Ebitengine. It includes an optional starter, project helpers and references
for input, rendering, text, audio, gameplay, testing and distribution.

The starter and API examples target Ebitengine v2.10.6 / Go 1.25+. Existing
projects keep their `go.mod` version and any workspace/replacement configuration;
see [`VERSION-SUPPORT.md`](../../docs/VERSION-SUPPORT.md).

Start with [`ebitengine-game`](ebitengine-game/SKILL.md). Read only its references
needed for the task; a focused fix does not require generating a new project.

See [`docs/SKILL-FORMAT.md`](../../docs/SKILL-FORMAT.md) for the authoring standard.
